# MASTERMIND implementation agreement

## Approved direction
SLOP4408 — MASTERMIND: The Academy of Impossible Skills is a playable, third-person SlopU academy. Twelve distinct capabilities accumulate into Operation Last Light at fictional Meridian Station. Teach a skill, let the student practise, test it, then transfer it. Evidence and reflection support practical learning. The user rejected the earlier abstract Glass Crown curriculum; do not reintroduce it as the active course.

## Platform and publishing
Keep Astro, strict TypeScript, Node 24 / pnpm 11.9.0 through mise in WSL, SlopU branding, suffix 408, four collections, generated API, build/deploy integrations and secret checks. Use the repository base path everywhere. Three.js and Rapier enhance the static website. No backend, accounts, live AI, external runtime services or multiplayer server. Commit locally without signing; the user will push.

## Teaching and experience
- Observation, memory, spatial reasoning, mechanisms, electronics, digital investigation, fictional permissions, communication, role-play, simulated sensors, improvisation and recovery are different activities with real cause and effect.
- Every week has substantial briefing, guided practice, skill check, unfamiliar transfer task, explanatory feedback, campus equivalent and reusable evidence.
- Campus and browser routes target the same concepts; browser practice does not certify physical dexterity. Memory means trained recall, and deception assessment means checking evidence.
- Use original fictional training systems. No real intrusion, vehicle bypass or evasion procedures.
- Third-person exploration, expressive original characters, detailed workbenches and stylised cinematic environments. Conventional navigation remains available. No content gates.
- Assessments: best ten fieldwork records 10%; individual workshop trial 20%; paired relay 25%; four-role recovery 45%. Endings are not academic grades.
- Shared local mission, distinct role information/tools, rotating control and solo switching. Preserve original plans and revisions.

## Reliability and evidence
Keep domain rules independent of graphics. Every activity has semantic interactive controls and static teaching alternatives. Test keyboard/touch, 1920×1080 and 390×844, reduced motion, slow loading, resize and WebGL failure. A viewport screenshot does not establish phone performance.
Version new saves; preserve legacy data for explicit export. Validate imports before replacement. Storage errors retain usable state and same-page export. Render imported text as text. Detect other-tab edits.
Run pnpm check, pnpm check:evidence and course browser tests. Record actual review observations and failures. Local success does not imply publishing, CI or live acceptance.
PROCESS.md remains a 400–600-word account edited from the student's supplied reasoning. Never invent personal review, playtesting, citations or acceptance. Preserve honest history, including the rejected first design. No guaranteed grade.
