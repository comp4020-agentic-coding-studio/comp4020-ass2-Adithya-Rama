## Before you arrive

Read E07 alongside E03; bring Version 1 (20 minutes). Direct visitors can load a clearly labelled sample.

Bring plan v1. If you are entering this week directly, use the labelled example in the activity. It supplies a starting point and does not count as your original work.

## The two-hour lab

| Time | Work |
| --- | --- |
| 0–15 min | Read the case file and name the decision the evidence affects. |
| 15–35 min | Annotate a copy of Version 1. Mark affected dependencies, unaffected decisions and questions still needing evidence. Then save Version 2 and compare the two records. |
| 35–70 min | Complete the playable exercise below; record a reason before inspecting the feedback. |
| 70–95 min | Exchange explanations. Challenge one assumption using a specific source. |
| 95–110 min | Revise the output and explain which part of the feedback changed it. |
| 110–120 min | Save or export the record and write the closing reflection. |

## What leaves the room

**plan-v2** is this week's named artefact. Submit both versions and the diagnosis in A2. The final project must use the same discipline when goals or crew agreement change.

Include your decision, the case-file identifier, a justification, and one remaining limitation. Keep both versions: the revised plan is assessed alongside its preserved original.

## How to judge the response

Deleting Version 1 to make the archive consistent destroys the evidence of revision. Repeating the old test more times is equally unhelpful: it establishes consistency with the wrong protocol.

A strong response explains a particular choice and an alternative. The supplied exemplar is inspectable feedback, not a sentence you must copy. Your confidence or reflection is never assigned an automatic academic grade.

## Closing reflection

How did you distinguish a necessary change from an attractive but unrelated redesign?
